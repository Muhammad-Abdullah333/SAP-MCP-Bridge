Built in the open, from public sources.

## What's fixed

- **The manager opening as an empty white window.** The manager could stay blank on every launch, however many times you closed and reopened it. It relied on a note left by its previous run, and that note could look current long after the run had ended. It now checks that the server it remembers really is there, and starts a new one if it isn't.

Your connections, passwords and certificates are kept when you update.

## Download

Download **SAP-MCP-Desktop-Bridge-1.0.4-Windows-Setup.exe** below and run it. You need Windows 10 or 11 and Claude Desktop or Codex. Nothing else to install: the installer includes its own Node.js runtime.

The installer isn't code-signed yet, so Windows shows a SmartScreen notice the first time: choose **More info → Run anyway**. You can check the download against `SHA256SUMS-1.0.4.txt`. If your antivirus flags it, please open an issue rather than turning the antivirus off.

If the app helps you, a ⭐ on the repository helps other SAP developers find it.
