## Two editions

From this release Bridge comes in two editions. Both do the same work and connect Claude Desktop and Codex the same way.

- **Desktop edition** (`SAP-MCP-Desktop-Bridge-1.0.6-Windows-Setup.exe`, about 122 MB, down from about 140 MB): the manager opens in its own app window, as before. It is smaller than 1.0.5 because it no longer carries 54 unused interface languages and an unused graphics compiler.
- **Web edition** (`SAP-MCP-Desktop-Bridge-1.0.6-Windows-Web-Setup.exe`, about 29 MB): the manager opens as a tab in your default browser. A small console window, minimized, shows that it is running; close it to stop the manager. It also stops by itself 10 minutes after the last tab closes. If no tab opens, press Enter in that window: it opens the manager again and shows a one-time link you can paste into your browser.

To switch, install the other edition over the one you have. Your connections, passwords, certificates and client setup are kept. Claude Desktop and Codex never need the manager to be open.

Uninstalling now also closes a Bridge MCP server that Claude Desktop or Codex still has running, so nothing is left behind in the install folder.

## Safer opening of the manager

The manager page no longer contains its access key. It opens through a one-time link from the Start menu icon, which gives that window or tab a private session. Another program, or another person signed in to the same computer (as on a shared Windows server), can no longer open the manager by visiting its local address. This applies to both editions.

## The SAP engine is up to date

The bundled engine moves from abap-adt-mcp 2.1.0 to 2.8.2, with Bridge's own safety-policy changes carried over. You get its fixes, among them:

- Calls no longer fail with "400" forever after a pause; the session is renewed and the call retried.
- Calls no longer hang after the computer was locked or asleep.
- Negative amounts keep their minus sign in query results.
- `setTextElements` writes text elements correctly.

Bridge adds its own fixes on top:

- **Many queries in a row** no longer end in a short dump (GENERATE_SUBPOOL_DIR_FULL) after about 36 of them: each query runs in its own short-lived session.
- **Positive amounts** come back as numbers too, not as text with a trailing blank.
- **runSnippet** says why the output is empty when the code uses `WRITE`, and a very large output is shortened cleanly instead of breaking the result.
- **dumps** accepts `brief` for one short line per dump.
- **sourceTextSearch** works on systems without a text index when given just the object name.

Reading table data works as before at both reading levels of the safety policy: a table you name can always be read, and the connection's own SQL only when its policy allows it.

## Download

Choose one of the two installers below and run it. You need Windows 10 or 11 and Claude Desktop or Codex. Nothing else to install: each installer includes its own Node.js runtime.

The installers aren't code-signed yet, so Windows shows a SmartScreen notice the first time: choose **More info → Run anyway**. You can check the downloads against `SHA256SUMS-1.0.6.txt`. If your antivirus flags one, please open an issue rather than turning the antivirus off.

If the app helps you, a ⭐ on the repository helps other SAP developers find it.
