Built in the open, from public sources.

## What's fixed

- **Releasing a transport with locked objects.** `transportRelease` with `ignoreLocks` (or `IgnoreATC`) failed with *System expected the element '{http://www.sap.com/cts/adt/tm}root'*. That is the usual case for a Transport of Copies whose objects are still locked in the original open request. The "release anyway" step now sends SAP the request it expects, the same one Eclipse ADT sends, so these transports release normally.

Your connections, passwords and certificates are kept when you update.

## Download

Download **SAP-MCP-Desktop-Bridge-1.0.3-Windows-Setup.exe** below and run it. You need Windows 10 or 11 and Claude Desktop or Codex. Nothing else to install: the installer includes its own Node.js runtime.

The installer isn't code-signed yet, so Windows shows a SmartScreen notice the first time: choose **More info → Run anyway**. You can check the download against `SHA256SUMS-1.0.3.txt`. If your antivirus flags it, please open an issue rather than turning the antivirus off.

If the app helps you, a ⭐ on the repository helps other SAP developers find it.
