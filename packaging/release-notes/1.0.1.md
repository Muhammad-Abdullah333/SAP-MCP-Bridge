Built in the open, from public sources.

## What's new

- **Silent install.** Run the installer with `/S` for unattended or managed installs: no windows, the app isn't opened, and the exit code reports the result (0 means success). If it fails, the reason is written to `%TEMP%\sap-mcp-bridge-install-error.log`.
- **Built by GitHub Actions from this repository.** The Node.js runtime and Electron are downloaded from their official sources and checked against pinned SHA-256 hashes. The MCP server and its dependencies are installed from npm exactly as locked, with integrity hashes. Every build publishes a fingerprint of the app's contents, so anyone can rebuild the same commit and compare.
- **Privacy policy** added to the repository: https://github.com/Muhammad-Abdullah333/SAP-MCP-Bridge/blob/main/PRIVACY.md

The app itself is unchanged from 1.0.0. Your connections, passwords and certificates are kept when you update.

## Download

Download **SAP-MCP-Desktop-Bridge-1.0.1-Windows-Setup.exe** below and run it. You need Windows 10 or 11 and Claude Desktop or Codex. Nothing else to install: the installer includes its own Node.js runtime.

The installer isn't code-signed yet, so Windows shows a SmartScreen notice the first time: choose **More info → Run anyway**. You can check the download against `SHA256SUMS-1.0.1.txt`.

If the app helps you, a ⭐ on the repository helps other SAP developers find it.
