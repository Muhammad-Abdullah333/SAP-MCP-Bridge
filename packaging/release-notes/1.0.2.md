## What's new

Microsoft Defender and other antivirus products flagged 1.0.0 and 1.0.1 with generic machine-learning detections such as `Trojan:Win32/Sabsik.EN.B!ml`. Those were false positives, caused by how the installer and the app were built. This release removes every pattern behind them:

- **A standard installer.** The installer is now built with Inno Setup instead of a custom program that unpacked itself and ran hidden PowerShell. It shows a normal setup window and lets you choose whether to connect Claude Desktop and Codex. The app now appears in **Settings → Apps**, so you can uninstall it from there like any other app.
- **No hidden PowerShell.** The app used to start a hidden PowerShell script every time it saved or read a password. It now calls Windows' own password encryption (DPAPI) directly. Passwords you've already saved keep working: the encryption and file format are unchanged.
- **No scripts in the app.** The VBScript launcher, the batch file and the PowerShell uninstall and rollback scripts are gone.
- **The app's own name and publisher.** The app's executable now describes itself as SAP MCP Connection Manager instead of Electron.
- **Imports only when you ask.** The manager no longer looks for older vaults and abap-adt-mcp settings every time it starts. Use **Import existing connections** or **Choose original vault** to import them.

Also:

- Updating while the manager or Claude Desktop or Codex is running now works. The installer closes the Bridge programs that are running (only its own) and opens nothing. Restart Claude Desktop or Codex afterwards.
- If Claude Desktop or Codex can't be connected during setup, the app is still installed and their settings are left exactly as they were. The installer and the manager now say why in plain language and how to fix it, for example a mistake in the client's settings file or a file held open by another program. If neither client is installed yet, the installer tells you how to connect one later.
- A settings file that contains a mistake is now reported as such, with the line where the problem is, instead of a raw parser error.
- The Setup Guide and README have a new section, *If Claude Desktop or Codex isn't connected*, covering each cause, including a Claude Desktop that is still running in the system tray.
- Unattended installs now use `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` instead of `/S`. Exit code 0 means success; 10 means the app is installed but the clients couldn't be connected (the reason is in `%TEMP%\sap-mcp-bridge-install-error.log`). Add `/MERGETASKS="!clients"` to skip connecting them.
- Copies of earlier versions that updates used to keep next to the app are removed.

Your connections, passwords and certificates are kept when you update.

## Download

Download **SAP-MCP-Desktop-Bridge-1.0.2-Windows-Setup.exe** below and run it. You need Windows 10 or 11 and Claude Desktop or Codex. Nothing else to install: the installer includes its own Node.js runtime.

The installer isn't code-signed yet, so Windows shows a SmartScreen notice the first time: choose **More info → Run anyway**. You can check the download against `SHA256SUMS-1.0.2.txt`. If your antivirus flags it, please open an issue rather than turning the antivirus off.

If the app helps you, a ⭐ on the repository helps other SAP developers find it.
