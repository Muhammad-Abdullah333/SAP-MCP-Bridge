Built in the open, from public sources.

## What's fixed

- **Package limits on a test client.** On a client closed for repository changes (a typical test client), `customOnly` and `allowedPackages` refused every call, including running your own `$TMP` or Z test class, with "could not determine the class package of the object". The package is now also read from ADT quick search, which needs no change authorization, so your own objects pass and standard ones are still refused. If the package still cannot be determined, the call is denied as before.
- **"Locked" on a client that is simply closed for changes.** On such a client, `runSnippet` and other changes failed with a hint that the object was locked and to check SM12. Nothing was locked: SAP refuses every change there (message TK730). The error now says so, and points to what still works on that client: reading data and running existing classes.

Your connections, passwords and certificates are kept when you update.

## Download

Download **SAP-MCP-Desktop-Bridge-1.0.5-Windows-Setup.exe** below and run it. You need Windows 10 or 11 and Claude Desktop or Codex. Nothing else to install: the installer includes its own Node.js runtime.

The download is about 140 MB because it carries its own browser engine for the manager window and its own Node.js, so nothing else has to be downloaded or installed. The Bridge itself is a few MB of that; a smaller installer is planned.

The installer isn't code-signed yet, so Windows shows a SmartScreen notice the first time: choose **More info → Run anyway**. You can check the download against `SHA256SUMS-1.0.5.txt`. If your antivirus flags it, please open an issue rather than turning the antivirus off.

If the app helps you, a ⭐ on the repository helps other SAP developers find it.
